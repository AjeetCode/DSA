What is difference between normal folders and databases?
	"A folder is just a storage location for files, whereas a database not only stores data but also organizes, relates, secures, and retrieves it efficiently using queries. In simple terms, a folder stores information, but a database helps you manage and use that information intelligently."
If the interviewer asks for an example:
	"For example, I can store thousands of student files in folders, but if I want all students with marks above 80%, a database can find them instantly using a query, while folders cannot."

Types of databases?
Databases are mainly of two types: Relational databases, which store data in tables (e.g., MySQL), and NoSQL databases, which store flexible, unstructured data (e.g., MongoDB). Other types include hierarchical, network, object-oriented, and distributed databases.

Sql, mySql or postgerySql, databases.
"SQL is a query language used to communicate with relational databases. MySQL and PostgreSQL are DBMSs that store and manage databases and understand SQL commands."




"Can we create a database without a DBMS?"
	Yes, technically we can store data in files and create our own logic to manage it. However, without a DBMS we would have to handle searching, updating, deleting, security, concurrency, backups, and data integrity ourselves. That's why DBMSs like MySQL, PostgreSQL, and MongoDB are used in real-world applications.

The most common questions asked in the interviews about sql?
1. What is a Database?
Answer:
A database is an organized collection of data that can be stored, managed, and retrieved efficiently.
Example: Student records, employee details, product information.

2. What is DBMS?
Answer:
A Database Management System (DBMS) is software used to create, manage, and manipulate databases.
Examples:
	• MySQL 
	• PostgreSQL 
	• MongoDB 

3. What is SQL?
Answer:
SQL (Structured Query Language) is a language used to communicate with relational databases.
Example:

SELECT * FROM Student;

4. What is the Difference Between SQL and MySQL?
Answer:
SQL	MySQL
Language	DBMS
Used to write queries	Used to store/manage databases
Standard language	Software
Interview Line:
	SQL is the language, while MySQL is a DBMS that understands SQL.

5. What is a Primary Key?
Answer:
A Primary Key uniquely identifies each row in a table.

CREATE TABLE Student(
    id INT PRIMARY KEY,
    name VARCHAR(50)
);
Example:
id	name
1	Ajeet
2	Rahul
id is the Primary Key.

6. What is a Foreign Key?
Answer:
A Foreign Key creates a relationship between two tables.

CREATE TABLE Orders(
    order_id INT PRIMARY KEY,
    customer_id INT,
    FOREIGN KEY(customer_id)
    REFERENCES Customer(id)
);

7. Difference Between DELETE, TRUNCATE, and DROP?
DELETE					TRUNCATE			DROP
Deletes selected rows	Deletes all rows	Deletes table
Can use WHERE			Cannot use WHERE	Removes structure
Can rollback			Faster				Table no longer exists

Example:
DELETE FROM Student WHERE id=1;

8. What is the Difference Between WHERE and HAVING?
WHERE
	• Filters rows before grouping. 

SELECT * FROM Student
WHERE marks > 80;
HAVING
	• Filters groups after grouping. 

SELECT department, COUNT(*)
FROM Employee
GROUP BY department
HAVING COUNT(*) > 5;

9. What are Joins?
Answer:
Joins combine data from multiple tables.
Common Joins
	• INNER JOIN 
	• LEFT JOIN 
	• RIGHT JOIN 
	• FULL JOIN 
Example:

SELECT c.name, o.order_id
FROM Customer c
INNER JOIN Orders o
ON c.id = o.customer_id;
This is one of the most asked SQL topics.

10. What is the Difference Between WHERE and GROUP BY?
WHERE
	• Filters records. 

SELECT * FROM Employee
WHERE salary > 50000;
GROUP BY
	• Groups similar records. 

SELECT department, COUNT(*)
FROM Employee
GROUP BY department;

What are Clauses in SQL?
Clauses are keywords or parts of an SQL query that perform specific tasks. They help us filter, sort, group, or limit data in a query.
Clause	Purpose
SELECT	Select columns.
FROM	Specify table.
WHERE	Filter rows.
ORDER BY	Sort data.
GROUP BY	Group similar records.
HAVING	Filter groups.
DISTINCT	Remove duplicates.
LIMIT	Restrict number of rows returned.

Creating tables : 

CREATE TABLE customer (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(50),
    email VARCHAR(100),
    city VARCHAR(50)
);

CREATE TABLE product (
    product_id INT PRIMARY KEY,
    product_name VARCHAR(50),
    price DECIMAL(10,2),
    category VARCHAR(50)
);

CREATE TABLE orders (
    order_id INT PRIMARY KEY,
    customer_id INT,
    product_id INT,
    quantity INT,
    order_date DATE,
    FOREIGN KEY (customer_id) REFERENCES customer(customer_id),
    FOREIGN KEY (product_id) REFERENCES product(product_id)
);

CREATE TABLE payment (
    payment_id INT PRIMARY KEY,
    order_id INT,
    amount DECIMAL(10,2),
    payment_method VARCHAR(20),
    payment_date DATE,
    FOREIGN KEY (order_id) REFERENCES orders(order_id)
);

CREATE TABLE rating (
    rating_id INT PRIMARY KEY,
    customer_id INT,
    product_id INT,
    rating INT,
    review VARCHAR(100),
    FOREIGN KEY (customer_id) REFERENCES customer(customer_id),
    FOREIGN KEY (product_id) REFERENCES product(product_id)
);

INNER JOIN. 
"Give me ALL columns from BOTH tables."

SELECT *

RIGHT JOIN

SELECT *
FROM customer c
RIGHT JOIN orders o

	Keep ALL rows from the RIGHT table (orders).
	For matching rows, bring data from the left table (customer).

select c.customer_name, p.product_name from customer c inner join orders o on c.customer_id = o.customer_id inner join product p on p.product_id = o.product_id;

select o.order_id, p.product_name, o.quantity from orders o inner join product p on p.product_id = o.product_id;
-- Display product name and its category for every order.
select p.product_name, p.category from product p inner join orders o on p.product_id = o.product_id;
-- Display customer name, product name, and order date.
select c.customer_name, p.product_name, o.order_date from customer c inner join orders o on c.customer_id = o.customer_id inner join product p on p.product_id = o.product_id;
-- Display payment amount along with customer name.
select p.amount, c.customer_name from customer c inner join orders o on o.customer_id = c.customer_id inner join payment p on o.order_id = p.order_id;
-- Display payment method and product name.
select pr.product_name, pa.amount from product pr inner join orders o on o.product_id = pr.product_id inner join payment pa on o.order_id = pa.order_id;
